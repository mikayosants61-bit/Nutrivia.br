# Nutrivia.br
Plataforma web para nutricionistas: calcula metas (TMB, GET e macros), monta cardápios com totais em tempo real e trocas de alimentos, gera prescrição técnica e versão para o paciente, cria lista de compras e envia o plano por WhatsApp ou e-mail com a logo do profissional. Dados salvos no navegador. Ferramenta de apoio ao nutricionista.
